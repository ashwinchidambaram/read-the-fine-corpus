# MUST Traceability Matrix

This page captures every binding requirement in the Read The Fine Corpus engineering specification (v0.1), mapped to where the design addresses it, which build phase implements it, and which test layer proves it. It is updated at every phase; an unmapped row is an open item and must never be left silent. The columns "Design ref", "Phase", "Test layer", and "Status" are maintained by the orchestrator as the build progresses. The matrix was first fully mapped at design review, 2026-09-03.
